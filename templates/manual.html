อ่านจบ 5 นาที ใช้เป็นเลย — สำหรับเจ้าของหอที่ยังไม่เคยใช้

← กลับไปหน้าที่แล้ว

🚀 1. สมัครใช้งาน (ฟรี 30 วันแรก)

  1. เปิดหน้า หน้าlogin → กดปุ่ม สมัครใช้งาน
  2. กรอกข้อมูล: Username, รหัสผ่าน, ชื่อหอพัก, เบอร์พร้อมเพย์ (เบอร์ที่รับเงินค่าเช่า), เรทน้ำ/ไฟ
  3. กดสมัคร → เข้าใช้ได้ทันที ฟรี 30 วัน
⏰ ครบ 30 วัน → ระบบล็อกอัตโนมัติ → กด ต่ออายุ → สแกน QR 399฿/เดือน → จ่าย + อัปสลิป → ระบบตรวจผ่าน → ใช้งานต่อทันที

🧾 2. ต้องเตรียมอะไรบ้าง / ไปเอาจากไหน

ของที่ต้องมีเอามาจากไหนจำเป็นไหม
เบอร์พร้อมเพย์ (รับเงินค่าเช่า)เบอร์โทร/เลขบัตรที่ผูกพร้อมเพย์ไว้แล้ว — ตั้งในแอปธนาคารของคุณจำเป็น
รหัสสาขา SlipOKผู้ให้บริการ (Super Admin) เป็นคนสร้างสาขา + ตั้งให้ — คุณไม่ต้องทำเฉพาะแบบตรวจอัตโนมัติ
LINE OA (ส่งบิลแจ้งเตือน)สมัคร LINE Official Account ที่ line.me/business (ฟรี) + LINE Developers เอา Access Tokenไม่บังคับ (ข้ามไปได้)

⚙️ 3. ระบบทำงานยังไง (คร่าวๆ)

1️⃣ เพิ่มห้อง: เลขห้อง + ชื่อผู้เช่า + ค่าเช่า + เลขมิเตอร์เริ่มต้น
2️⃣ สิ้นเดือน: กรอกเลขมิเตอร์ใหม่ → ระบบคิดค่าน้ำ/ไฟ + ค่าเช่า = ยอดบิล → สร้าง QR ให้อัตโนมัติ
3️⃣ ส่ง QR/ลิงก์ให้ผู้เช่า (ก็อปปี้ส่ง LINE ได้เลย) → ผู้เช่าสแกนจ่าย → อัปสลิป
4️⃣ ระบบตรวจสลิป → ผ่าน = บิลขึ้น "จ่ายแล้ว" ✅ → Export Excel สรุปสิ้นเดือน

👀 แบบที่ 1: เช็คสลิปแบบมือ (ฟรี ไม่ต้องซื้อเพิ่ม)

วิธีใช้

ไม่ต้องตั้งค่าอะไรเลย — ผู้เช่าส่งสลิป → ระบบเก็บรูปสลิปไว้ → หน้า Admin เห็นบิลขึ้น "รอตรวจ" → คุณเปิดดูรูป → กด อนุมัติ (หรือปฏิเสธ)

ได้อะไร

✅ ใช้ได้ฟรีทันที / ✅ กันสลิปซ้ำ
⚠️ แต่คุณต้อง นั่งเปิดดูสลิปเองทุกใบ

⚡ แบบที่ 2: เช็คสลิปอัตโนมัติ (Add-on 199฿/เดือน / 250 ครั้ง)

วิธีเปิดใช้

  1. หน้า Admin → แท็บ ตรวจสลิป → กด เปิดใช้งาน 199฿
  2. สแกน QR → จ่าย 199 → อัปสลิป → ระบบตรวจผ่าน → เปิดใช้ทันที ได้ 250 ครั้ง/เดือน
  3. ส่วนการตั้งสาขา ผู้ให้บริการเป็นคนทำให้ — คุณไม่ต้องแตะอะไร

ได้อะไร (ต่างจากแบบ 1 ตรงไหน)

ผู้เช่าส่งสลิป → ระบบ ตรวจกับธนาคารอัตโนมัติ → ผ่าน = บิลจ่ายทันที โดยที่คุณไม่ต้องเปิดดู
✅ ตรวจเจอสลิปปลอม / สลิปซ้ำ / ยอดเงินไม่ตรงบิล / สลิปเก่าเกิน 15 นาที
✅ ประหยัดเวลา — ไม่ต้องนั่งดูสลิปทีละใบ

💬 LINE Webhook (ขั้นสูง — เจ้าของหอตั้งเองได้ ~30 นาที)

  1. สร้าง LINE Official Account ฟรีที่ line.me/business (ตั้งชื่อหอคุณ)
  2. เข้า developers.line.biz → สร้าง Provider → สร้าง Messaging API channel → ผูกกับ LINE OA
  3. หน้า Admin → แท็บ LINE → วาง Channel Access Token + Channel Secret (ก็อปปี้จาก LINE Developers) → บันทึก
  4. ก็อปปี้ Webhook URL → ไป LINE Developers → แท็บ Messaging API → Webhook settings → วาง URL → เปิด Use webhook → กด Verify (ต้องขึ้น Success)
  5. แอดไลน์บอท (สแกน QR / กดลิงก์ line.me/R/ti/p/@ไอดีบอท) → ส่งข้อความอะไรก็ได้ → ระบบจำ LINE ID ให้อัตโนมัติ → เอาไปใส่ Owner LINE User ID
  6. ผู้เช่า: ให้ผู้เช่าแอดไลน์บอทก่อน → ระบบเก็บ ID ผู้เช่า → เอาไปใส่ช่อง "LINE User ID" ตอนเพิ่มห้อง → ระบบส่งลิงก์บิลหาผู้เช่าได้
💡 ข้ามขั้นตอนนี้ได้เลยถ้าไม่อยากยุ่ง — ระบบยังใช้ได้ครบ แค่ไม่มีแจ้งเตือน LINE
